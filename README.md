## 🗄️ Drizzle Kit - Scripts


| Script                   | Descrição                                                                                                                   |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `pnpm generate generate` | Gera arquivos de migração SQL com base no seu esquema Drizzle, seja mediante declaração ou em alterações subsequentes.      |
| `pnpm migrate`           | Aplica arquivos de migração SQL gerados ao seu banco de dadosos.                                                            |
| `pnpm studio`            | Conecta ao seu banco de dados e cria um servidor proxy para o Drizzle Studio, para navegação conveniente no banco de dados. |
| `pnpm check`             | Percorre todas as migrações geradas e verifica quaisquer condições de corrida (colisões) das migrações geradas.             |
| `pnpm up`                | Atualiza instantâneos de migrações geradas anteriormente.                                                                   |
